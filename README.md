# Nightfall Horror

A dark, cinematic horror movie and TV show app featuring:
- new horror releases
- best kills and iconic moments
- horror TV recommendations
- all-time classics
- watchlist tracking
- searchable and filterable catalog

## Run locally

Open `index.html` in a browser, or serve the folder with a small local web server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files
- `index.html` — app shell and sections
- `styles.css` — horror-themed dark UI styling
- `app.js` — mock catalog data and filters

## Notes
This version is a front-end prototype using curated horror data and no external API key needed.
